# TaurusDB MySQL 对接华为云 MaaS 需求与验收基线

目标版本：2026-09-30
状态：评审稿

## 1. 业务场景、交付范围、规格和指标

### (1) 文本向量化

支持应用通过 `AI_EMBEDDING()` 调用华为云 MaaS 文本向量模型。支持 `bge-m3`，输出
1024 维向量。

验收要求：`AI_EMBEDDING()` 能够返回 1024 维有效向量；无权限、模型不可用、维度错误或
凭据错误时必须失败；数据库可本地判断的失败不得访问 MaaS。

### (2) 向量数据写入和 RAG 检索

支持将 `AI_EMBEDDING()` 输出写入向量列；支持使用 `STORED` 生成列自动生成向量；支持
向量索引、标量过滤和 RAG 检索。

验收要求：能够使用文档向量完成 RAG 检索，不得返回无访问权限的数据；插入、更新文档时
能够生成 embedding，更新非文档字段不得产生额外调用。

### (3) SQL 结果分析与 DBA 诊断

支持通过 `AI_ANALYZE()` 调用华为云 MaaS 文本生成模型，用于 SQL 结果摘要、分类、抽取、
RAG 回答和智能诊断。诊断只返回原因、证据、建议与风险，不执行自动修复 SQL。

验收要求：`AI_ANALYZE()` 能够调用已配置的文本生成模型，并返回非空内容。

### (4) 模型配置和权限控制

支持管理员新增、更新、停用和切换模型配置。`AI_ADMIN` 用于模型配置管理，`AI_INVOKE`
控制 AI 模型调用；拥有 `AI_INVOKE` 的账号可调用已启用的模型。

验收要求：模型停用后，后续调用必须失败；无 `AI_INVOKE` 的账号调用 AI 接口必须失败。
生产环境必须使用安全凭据引用，不允许输出真实 API Key。

### (5) 调用审计和主备支持

支持记录模型调用成功或失败、执行耗时、Token 用量、模型、用户和客户端 IP 等脱敏信息。
主机和备机均支持模型调用和调用审计；主机支持模型配置管理。

验收要求：开启审计后，每次外部模型调用均记录起始和最终状态；审计写入失败时不得发起
模型调用；审计日志不得包含 API Key、完整请求、完整响应或原始向量。主机和备机均能够
完成 Embedding 和 Analyze 调用，并生成审计日志。

### (6) 构建、基本测试和验收证据

Release 构建成功；DB4AI 基本功能测试通过。

2026-09-30 前提交可复跑、脱敏的功能验收报告，包括构建版本、模型配置、调用结果、错误分类、
审计日志和日志脱敏检查结果。

### (7) 性能

当前版本仅完成 Demo 和功能验证，不提供 P50/P95/P99、QPS、并发或吞吐等性能承诺。
模型调用时延和吞吐能力依赖华为云 MaaS 服务、网络路径、模型规格和服务配额；后续在
生产目标环境完成性能测试后，再单独定义性能指标。

## 2. 约束和限制

### (1) 同步调用

只支持同步调用，暂不支持异步和批量调用；不适用于高并发 OLTP、无界大表扫描和在线批量处理。

### (2) 超时和费用

请求超时、连接中断或事务回滚时，MaaS 仍可能已接收请求并产生费用；默认不自动重试。

### (3) STORED 生成列

使用 `STORED + AI_EMBEDDING()` 时，需要满足 `binlog_row_image=MINIMAL`；否则非文档字段
更新可能触发额外模型调用。

### (4) 权限范围

当前采用实例级权限控制，不支持按用户、模型、预算或配额进行细粒度授权。

### (5) 网络和模型范围

每个上线 Region 需单独完成 MaaS 网络连通性验证。新 Provider、新协议、多模态、流式输出、
工具调用和异步任务不在本版本范围。

### (6) 审计日志

审计日志用于运维与追溯，不支持通过普通 SQL 直接查询。
