# TaurusDB MySQL 对接华为云 MaaS 需求与验收基线

目标版本：2026-09-30
状态：评审稿

## 1. 明确业务场景和交付范围

### (1) 文本向量化

支持应用通过 `AI_EMBEDDING()` 调用华为云 MaaS 文本向量模型。支持 `bge-m3`，输出
1024 维向量。

### (2) 向量数据写入和 RAG 检索

支持将 `AI_EMBEDDING()` 输出写入向量列；支持使用 `STORED` 生成列自动生成向量；支持
向量索引、标量过滤和 RAG 检索。

### (3) SQL 结果分析与 DBA 诊断

支持通过 `AI_ANALYZE()` 调用华为云 MaaS 文本生成模型，用于 SQL 结果摘要、分类、抽取、
RAG 回答和智能诊断。诊断只返回原因、证据、建议与风险，不执行自动修复 SQL。

### (4) 模型配置

支持管理员新增、更新、停用和切换模型配置。华为云 MaaS 推出兼容的新模型或新版本模型时，
管理员可以配置并使用新模型。

### (5) 权限控制

`AI_ADMIN` 用于模型配置管理，`AI_INVOKE` 控制 AI 模型调用。拥有 `AI_INVOKE` 的账号可
调用已启用的模型。

### (6) 模型调用审计

支持记录模型调用成功或失败、执行耗时、Token 用量、模型、用户和客户端 IP 等脱敏信息。

### (7) 主机和备机支持

主机和备机均支持模型调用和调用审计；主机支持模型配置管理。

## 2. 具体规格、指标是什么

### (1) 构建和回归

Release 构建成功；DB4AI GUnit 和 MTR 回归 100% 通过。

### (2) Embedding

连续执行 100 次 `AI_EMBEDDING()`：100% 返回 1024 维有效向量。无权限、模型不可用、
维度错误或凭据错误时，调用必须失败；数据库可本地判断的失败不得访问 MaaS。

### (3) Analyze

连续执行 50 次 `AI_ANALYZE()`：成功率不低于 98%，成功响应必须返回非空内容。

### (4) 模型配置

管理员能够新增、发布、停用和回滚模型配置。模型停用后，后续调用必须失败。生产环境必须
使用安全凭据引用，不允许保存或输出真实 API Key。

### (5) 权限和审计

无 `AI_INVOKE` 的账号调用 AI 接口必须失败。开启审计后，每次外部模型调用均记录起始和
最终状态；审计写入失败时不得发起模型调用。审计日志不得包含 API Key、完整请求、完整响应
或原始向量。

### (6) RAG 和 STORED 生成列

使用 50 篇文档和 20 个问题验收 RAG，`Recall@3` 不低于 90%，不得返回无访问权限的数据。
插入、更新文档时生成正确数量的 embedding；更新非文档字段不得产生额外调用。

### (7) 主备调用

主机和备机分别完成真实 Embedding 和 Analyze 调用，均成功生成审计日志。

### (8) 性能

- Embedding 单并发 100 次：P95 不高于 5 秒，P99 不高于 10 秒，成功率不低于 99%。
- Embedding 4 并发 200 次：P95 不高于 8 秒，P99 不高于 15 秒，成功率不低于 98%。
- Analyze 单并发 50 次：P95 不高于 15 秒，P99 不高于 30 秒，成功率不低于 98%。

### (9) 验收证据

2026-09-30 前提交可复跑、脱敏的验收报告，包括构建版本、模型版本、网络路径、性能数据、
错误分类、审计计数和日志脱敏检查结果。

## 3. 约束和限制

### (1) 同步调用

只支持同步调用，暂不支持异步和批量调用；不适用于高并发 OLTP、无界大表扫描和在线批量处理。

### (2) 超时和费用

请求超时、连接中断或事务回滚时，MaaS 仍可能已接收请求并产生费用；默认不自动重试。

### (3) STORED 生成列

使用 `STORED + AI_EMBEDDING()` 时，需要满足 `binlog_row_image=MINIMAL`；否则非文档字段
更新可能触发额外模型调用。

### (4) 权限范围

当前采用实例级权限控制，不支持按用户、模型、预算或配额进行细粒度授权。

### (5) 网络和模型范围

每个上线 Region 需单独完成 MaaS 网络连通性验证。新 Provider、新协议、多模态、流式输出、
工具调用和异步任务不在本版本范围。

### (6) 审计日志

审计日志用于运维与追溯，不支持通过普通 SQL 直接查询。
